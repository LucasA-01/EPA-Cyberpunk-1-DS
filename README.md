# EPA-Cyberpunk-1-DS
## O trabalho consiste no desenvolvimento de um ambiente emulado (Máquina Virtual) que roda inteiramente de forma nativa e textual dentro do Prompt de Comando (CMD).

O objetivo principal é contornar as limitações visuais do terminal para renderizar e gerenciar processos de múltiplos jogos utilizando apenas caracteres ASCII ou pacotes de dados leves.

• Como Funciona: O projeto cria um sistema de arquivos e um interpretador lógico próprio através de scripts (geralmente em linguagens como Python, C++ ou Batch avançado). Esse "motor" simula o comportamento de um hardware básico, gerenciando memória e carregando minijogos direto na tela do CMD.

• Propósito: Mais do que apenas entretenimento, o trabalho visa demonstrar conceitos avançados de arquitetura de computadores, lógica de programação e gerenciamento de buffers sem a necessidade de uma interface gráfica (GUI) pesada, provando que é possível isolar e rodar aplicações leves em qualquer máquina através do terminal.
